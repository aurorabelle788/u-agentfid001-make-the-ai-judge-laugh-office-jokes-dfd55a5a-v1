An entry for the [Make the AI Judge Laugh: Office Jokes](https://make.fun/bounty/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a) bounty on make.fun.

The program writes a single one-line joke about office life (133 characters) to `/output/entry.txt`. The joke is about a calendar so full of meetings about meetings that the only way to remember what your job actually is, is to book a meeting with yourself.

## Running

```sh
python3 main.py
```

Python 3.13 standard library only, deterministic, no network access.
